# UCM Deployer v{VERSION}

**UCM (Unified Cache Management) 安装、环境预检与服务部署工具 —— Windows 桌面版**

面向 vLLM / vLLM-Ascend / SGLang 运行环境（Ascend NPU / NVIDIA GPU），提供五个向导步骤（另含面向多台服务器的可选批量部署）：

```
① 服务器管理 → ② 镜像准备 → ③ 容器准备 → ④ 环境预检 → ⑤ 服务部署（可选：批量部署）
```

## 本版本更新

- **新增步骤5「服务部署」操作指引页**：按操作顺序给出三个模块——① UCM 配置文件参考默认配置（`UcmPipelineStore` / `Cache|Posix` 存储）与参数说明官方网址（华为文档，可点击跳转）；② 推理服务拉起命令模板与注意事项（需先导出 `ENABLE_UCM_PATCH=1`、`VLLM_CPU_AFFINITY=1` 环境变量，命令附加 `--kv-transfer-config` 接入 UCMConnector，`UCM_CONFIG_FILE` 指向 UCM 配置文件路径）；③ 服务就绪后连通性验证 curl 模板（`/health`、`/v1/models`、`/v1/chat/completions` 完整示例）；所有内容可复制，展示框右下角可拖动调整高度。
- **界面全面改造（步骤1-5）**：
  - 步骤1 服务器管理：点选行即选定操作服务器，新增操作按钮区（添加/编辑/删除/测试连接/探测设备）、双击编辑与右键菜单、可拖动分栏与空状态引导；
  - 步骤2 镜像准备：进入自动扫描 UCM 镜像并逐个精确检查（找到即停、结果缓存复用）；
  - 步骤3 容器准备：**统一挂载表**——KV Cache / 模型 / 自定义挂载合并在同一张表格维护（一套按钮），KV Cache 行容器内路径自动锁定与宿主机相同；
  - 步骤4 环境预检：操作行整合，挂载目录随开关联动，结果摘要置顶；
  - （可选）批量部署：布局自上而下顺序化，目标服务器标明来自步骤1，挂载配置同步改为统一挂载表；
  - 主窗口：全部步骤页面支持小窗口内部滚动，窗口可自由缩放；多行配置框右下角**拖动手柄**可调整高度。
- **环境预检新增 SMMU 检查项**：宿主机 `dmesg` 检查 arm-smmu-v3（输出为 WARN，SMMU 开启会破坏 NPU 直通性能）；权限受限时 SKIP 避免误判。
- **任务面板**：任务完成后可导出当前页签日志（下载目录，UTF-8）。
- **测试**：新增服务部署 core/GUI、SMMU、统一挂载表、拖动手柄、日志导出等用例，全量 244 项通过。

## 主要功能

- **步骤1 服务器管理**：SSH 凭据本地加密保存/复用；自动探测设备型号、卡数与 CPU 架构。
- **步骤2 镜像准备**：支持服务器已有镜像、本地 tar 上传、镜像仓库拉取；自动探测基础镜像运行时并校验 UCM/wrapt/ucm-toolkit wheel 兼容性。
- **步骤3 容器准备**：选择 UCM 镜像自动校验安装情况；按宿主机实际存在的设备节点与系统挂载生成可编辑 `docker run` 命令；统一挂载表（KV Cache / 模型 / 自定义）。
- **步骤4 环境预检**：显式选择容器；检查驱动、内核、共享内存、AIO、存储带宽与 SMMU；UCM 与驱动版本支持多来源补齐；支持 JSON 参数叠加配置。
- **步骤5 服务部署**：UCM 配置参考模板、拉起命令模板（含环境变量与 --kv-transfer-config 接入）与连通性验证指引，一键复制照做即可。
- **（可选）批量部署**：多服务器镜像分发、容器创建与环境预检；部署数据模板导出/导入。
- **工具菜单**：按关键字筛选并清理容器/镜像，删除前展示完整确认列表。

## 使用

双击 `UCM-Deployer.exe` 即可（无需 Python）。产物自检：

```powershell
.\UCM-Deployer.exe --smoke
```

源码运行 / 开发见 [README](https://github.com/ucm-system/UCM-Deployer#readme)。
