# 步骤5 · 服务部署

选择目标容器后，**一键**完成两件事：

1. 把 **UCM 配置文件**写入容器内指定路径；
2. 按**推理服务拉起命令**在容器内后台启动推理服务。

两个输入框通过「容器内路径」衔接：配置内容写入容器内路径（默认 `/etc/ucm/config.yaml`），拉起命令直接引用该路径，推理服务启动时从该路径读取配置。

## 页面结构（双页签）

与批量部署的配置模板一致，配置区分为两个页签：

| 页签 | 内容 |
|---|---|
| **UCM 配置文件** | 配置文件路径（容器内，可改）+ 配置内容编辑框（已预填默认模板） |
| **推理服务拉起命令** | 拉起命令编辑框（默认为空，按实际填写） |

- 配置内容默认模板使用 `UcmPipelineStore` 连接器（`Cache|Posix` 存储管线），`storage_backends`、`posix_capacity_gb`、`posix_io_engine`、`posix_data_trans_concurrency` 等参数请**按实际存储环境修改**；
- 详细参数说明见配置框下方的 [UCM 参数配置说明（华为官方文档）](https://support.huawei.com/enterprise/zh/doc/EDOC1100582752/b4b5937b?idPath=7919749%7C251366268%7C250389224%7C263153904%7C268354339)（链接可点击跳转）；
- 拉起命令示例：

```bash
vllm serve /models/Qwen --ucm-config /etc/ucm/config.yaml ...
```

!!! tip "编辑框可拖高"
    两个编辑框右下角均有拖动手柄，上下拖动即可调整高度，方便粘贴长配置或长命令。

## 操作流程

1. **选择目标容器**：下拉选择步骤 3 创建的容器（或点「🔄 刷新容器」重新读取 `docker ps -a`）。
2. **确认/修改 UCM 配置**：默认模板通常只需修改 `storage_backends` 等存储参数。
3. **填写拉起命令**：命令中引用上方配置文件路径；留空时点击部署会被参数校验拦截。
4. **点击「🚀 部署UCM推理服务」**。

## 部署流水线

点击部署后按顺序执行，任一阶段失败即中止并给出原因：

| 阶段 | 行为 |
|---|---|
| 容器检查 | 确认容器存在且运行中，否则提示回步骤 3 |
| 写入配置 | 以 **base64** 方式写入配置（对引号/换行等特殊字符免疫），目录不存在自动创建 |
| 配置校验 | 回读容器内字节数与本地编码后大小比对，不一致即失败 |
| 拉起服务 | `nohup` 后台执行拉起命令，输出重定向到容器内 `/tmp/ucm-service.log` |
| 启动日志 | 2 秒后回读日志尾部 100 行，直接展示服务启动输出 |

!!! tip "日志可导出"
    部署日志面板常驻底部（部署前显示占位引导）。部署完成后可通过「⬇ 导出日志」把当前页签保存到下载目录（UTF-8 文本文件）。
